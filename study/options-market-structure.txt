# 「期权市场是有结构的」

## 零、一句话

股票市场只给你**一个数**（价格）。期权市场给你**一个曲面**，而且这个曲面
不能随便长 —— 它被逻辑锁死、被供需扭曲、被制度塑形。

「有结构」的意思是：**上千个期权合约的价格，真实自由度只有个位数。**

---

## 一、第一层：价格不是一个数，是一个曲面

一只股票，今天只有一个价格 S。

同一只股票的期权，在**每个到期日 T × 每个行权价 K** 上都有一个价格。把它们
换算成隐含波动率 σ(K, T)，就得到一张二维曲面 —— **波动率曲面**。

这就是第一层意思：观测对象的维度不一样。股票是点，期权是面。

## 二、第二层：无套利给曲面上了硬骨架

这是「结构」最硬的含义。同一到期日的 call 价格 C(K) 必须满足：

```
单调:  -e^{-rT} ≤ ∂C/∂K ≤ 0      牛市价差成本非负，且不超过贴现后的行权价差
凸性:  ∂²C/∂K² ≥ 0                蝶式价差成本非负
边界:  max(S - Ke^{-rT}, 0) ≤ C ≤ S
```

跨到期日：

```
日历:  总隐含方差 w = σ²·T 沿 T 不递减（沿固定 moneyness 路径）
```

跨 put/call：

```
平价:  C - P = S - Ke^{-rT}
```

**这些不是经验规律，是纯逻辑。** 违反了就存在确定性套利 —— 不需要任何模型
假设、任何概率判断，闭着眼睛就能把钱拿走。

所以期权价格不是自由飘的，它们被锁在一个凸的、有序的几何体里。这是骨架。

## 三、第三层：凸性 ⟺ 概率非负（关键洞察）

上面那条「凸性 ≥ 0」看起来像技术条件，其实不是。Breeden–Litzenberger：

```
q(K) = e^{rT} · ∂²C/∂K²
```

其中 q 是**风险中性概率密度**。

也就是说：

> **∂²C/∂K² ≥ 0 这条约束，就是「概率不能为负」这句话。**

这个等价关系是理解整件事的钥匙。它意味着：

1. 期权价格曲面 **等价于** 一个完整的概率分布
2. 曲面的无套利约束 **等价于** 那个分布的合法性
3. 你从期权市场读到的不是「市场预期涨到多少」，而是 **市场对整个分布的看法**
   —— 包括方差、偏度、峰度、尾部厚度

股票市场只能告诉你一个共识价。期权市场告诉你**共识的形状**。这是它独有的
信息，也是它最值得研究的地方。

## 四、第四层：结构是低维的

经验事实：波动率曲面的日变动，用三个因子就能解释绝大部分方差

- **Level**（水平）—— 整体波动率高低
- **Slope / Skew**（斜率）—— put 相对 call 的贵贱
- **Curvature**（曲率）—— 两翼相对 ATM 的凸起

上千个合约，实际自由度约等于 3。

这是「有结构」最实用的含义：**维度远低于表面维度**。也意味着 —— 你不需要
预测每个合约，你只需要预测这三个数怎么动。

## 五、结构从哪来

结构有三个来源，性质完全不同，混淆它们是很多人栽跟头的地方：

**1. 逻辑约束（第二、三节）** —— 永远成立。违反 = 数据错误，或真套利（99% 是前者）。

**2. 供需与仓位** —— 会变，但很持久：
- 保险/养老金**永远在买 put**（对冲需求单向）
- 结构化产品**持续在卖 call**（雪球、autocall 的 vega 供给）
- 这造成 skew 长期为负且不回归

**3. 制度与做市商行为**：
- Dealer net long gamma → 做市商在涨时卖、跌时买 → **抑制**波动
- Dealer net short gamma → 反向操作 → **放大**波动
- 到期日 pinning、保证金规则、vanna/charm flow

有个历史细节很说明问题：**1987 之前股票期权是 smile（两边翘），之后才变成
skew（左边翘）**。这说明 skew 里有一部分是**记忆**，不是逻辑 —— 市场记住了
崩盘。记忆会衰减，也会被重新唤醒。

## 六、对交易意味着什么

**「贵」是相对概念。**

绝对 IV 高低几乎没有信息 —— IV 30% 是贵是便宜，取决于同一曲面上的其他点。
可交易的从来不是「便宜的期权」，而是**结构的偏离**：

- 价差交易（跨行权价）
- Skew 交易（曲面斜率错位）
- 日历（期限结构错位）
- Dispersion（指数 vol vs 成分股 vol 的结构关系）

反过来说：**如果你的定价没有尊重结构，你算出来的「便宜」大概率是你自己的
模型误差，不是市场的错。** 这句话是下一节的全部内容。

---

## 七、落到你的 cb_arb 上

可转债 ≈ **债券 + 一个长期美式看涨期权（带回售/赎回/下修条款）**。

你的 `strategies/cb_arb/cb_pricer.py` 现在是这么给那个期权定价的：

```
realized_vol()  →  一个标量 stock_vol  →  塞进 Black-Scholes
（cb_pricer.py:275-281）
```

对照上面六节，这里有**三重结构缺失**：

**① 用历史波动率替代隐含波动率。**
两者系统性不相等 —— 波动率风险溢价的存在使 implied 长期高于 realized（成熟
市场约 2–4 个 vol point）。用 realized 喂 BS，等于假设这个溢价不存在。

**② Flat vol —— 假设曲面没有形状。**
转股权通常是价外 call。若标的存在负 skew，价外 call 的 IV **低于** ATM。用一个
不分行权价的 vol，会**系统性高估**这个期权的价值。

**③ 没有期限结构。**
可转债剩余期限 1–5 年。长端波动率和短端不是一回事，realized_vol 用的还是
短窗口的标准差。

**方向性后果（假设，需验证）：**如果期权价值被系统性高估，那么
「理论价值 − 市场价格」这个 gap 就会**系统性偏正** —— 你会把一批其实不便宜的
转债判成低估。

这跟你 experiments 里反复出现的那几个方向是同一件事的不同侧面：

- `option_value_haircut`（直接给期权价值打折）
- `option_false_undervaluation`（分析假性低估的来源）
- `iv_percentile_exit`（用 IV 分位数决定退出）

**它们都是在事后打补丁，修一个定价起点上的偏差。** 而如果偏差在起点，补丁
永远打不干净 —— 这可能就是成本墙一直过不去的原因之一。

### 但是：有个硬约束

**A 股没有个股期权。** 中国只有 ETF 期权（50/300/500ETF）和股指期权，个股期权
不存在。所以对绝大多数转债正股，**你根本观测不到隐含波动率曲面**。

结构是存在的，但对你的标的**不可观测**。这是真实约束，不能绕过去装作有数据。

### 那还能做什么

三条，按可行性排序：

**A. 常数校正（最容易，先做这个）**
估一个波动率风险溢价常数，把 realized vol 抬到 implied 的量级。哪怕只是
`vol * 1.15` 这种粗校正，也比默认 premium = 0 强。校正幅度用 ETF 期权的
implied-realized 长期差值来标定。

**B. 借形状（中等难度）**
从 50ETF/300ETF/500ETF 期权反解出市场级的 skew 和期限结构**形状**，把
level 用个股 realized vol，shape 用市场曲面。假设是「个股 skew 形状 ≈ 市场
skew 形状」—— 这个假设很粗，但比 flat 强，而且**可以被检验**。

**C. 反过来用（最有意思）**
不去猜期权该值多少，而是从转债市场价格**反解出市场隐含的转股权价值**，
再看这个隐含值跟你的模型值差在哪、差在什么条件下。这是把转债市场当成一个
（极不完美的）期权市场来读 —— 而它恰好是 A 股唯一有个股凸性定价的地方。

C 的价值在于：它不需要外部数据，且**直接检验**上面那个「系统性高估」假设 ——
如果隐含值持续低于模型值，假设成立。

---

## 八、一句话收尾

「期权市场是有结构的」这句话，往深里说是：

> 期权价格不是对未来的一个猜测，而是一个**被逻辑约束、被供需扭曲、被制度
> 塑形的低维几何对象**，它编码了市场对整个概率分布的看法。

往实处说是：

> **你不能孤立地判断一个期权贵还是便宜 —— 只能相对于结构判断。
> 而如果你的定价假设结构不存在，你算出来的「便宜」首先要怀疑的是自己。**
